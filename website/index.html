Frequently asked questions

Cryptographic guarantees behind Proof-Carrying Agent Execution (PCAE).

How fast does the full 7-gate + Merkle attestation run?

Across the 35-scenario benchmark suite, end-to-end 7-gate evaluation plus RFC 6962 Merkle tree construction executes in 0.2542 ms P50 and 0.5229 ms P95 in pure Python.

Can external CI runners verify a gate without seeing proprietary prompts?

Yes. nexus-aegis attest --disclose-gate G5_ANTI_REWARD_HACK outputs a redacted proof containing only the canonical gate verdict, 0x00 leaf digest, 4 sibling hashes, and the signed Merkle root.

Does tampering with a proof fail offline verification?

In benchmark testing across 245 inclusion proofs and 245 1-bit sibling mutations, verify_merkle_inclusion_proof achieved 100.00% valid proof verification and 100.00% tamper rejection.
